# PictuRAS · Suporte a Vídeo (Fase 1)

Repositório do Grupo 25 de Requisitos e Arquiteturas de Software (MEI, Universidade do Minho).

Aqui ficam os casos de uso da Fase 1 do PictuRAS, que especificam o suporte a vídeo na aplicação.

## Estrutura

- `casos-de-uso/`: um ficheiro Markdown por caso de uso, nomeado `UC-VID-nnn-descricao-curta.md`.

## Como trabalhar

- Cada um edita só o seu ficheiro.
- Fazer `git pull` antes de começar.
